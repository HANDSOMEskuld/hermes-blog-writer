# 示例风格库 (V1.2 浓缩样例)

> 这是一份**参考样例**，由「标杆文逐篇迭代」沉淀而来。使用者运行 `iterate_style.py`
> 后会生成自己的 `style_guide.md`，本文件仅作范式展示，可删除、可对照。

## 通用声音 (R1-R14, 所有类型)
- R1 现场钩子+行动感（"前两天我专门去试了下"）
- R2 玩耍感"一起玩/随便造/可玩的东西又多了"
- R3 真实场景而非抽象，亲测背书
- R4 免费低门槛贯穿
- R5 结尾干脆不拖（"OK，有任何问题评论区聊"）
- R6 大方示弱立信（"我不是专业的，原理让大佬科普"）
- R7 旧文互链成网 `[postsbox post_id="X"]`
- R8 数据/评价标来源「(来源：官网文档, 2026-08 核验)」
- R9 并列项用假想读者提问做承上启下（"有人会说，这都是国内的？"）
- R10 实操步骤来自真实检索、提示"路径以账号实际界面为准"、不编假路径
- R11 情感弧线：痛点(抑)→发现(扬)→坑(小抑)→一起玩(扬)
- R12 句子节奏：长短交错，禁连续长句堆叠 / 电报式碎短句
- R13 情绪词点缀增强传播力，不刻意堆砌（"坑/香/稳/绝了"）
- R14 结尾互动问句（"你有哪些舍不得删的？"）

## 文章类型与专属规则
### 教程 / 硬核技术 (R15-R20, R43-R44)
- 痛点反问开场 → 递工具；直说"项目变了"用 ^ 标
- 效果前置（先晒成果再讲步骤）
- 原理外包"大佬评论区科普"、利弊直说

### 游戏资源 (R27-R32, R39-R42)
- 固定四件套：百科介绍段 / 文件清单 / `[postsbox 48]` 互链 / 免责声明块
- 标题用 `|` 堆利益点

### 软件清单 (R41, R45)
- 用 `0x0`-`0xN` 十六进制小标题分大类
- 每项"软件名 + 真实用法 + 主观评价"
- 结尾升华 + 互动问句

### AI 工具教程 (R15-R20, R47)
- 实测数据（百分比/额度）+ ≥2 种免费方案
- 互链旧文

### 极简软件分享 (R48)
- 四段式短平快：痛点 + 工具 + 实机演示 + 好用方便

### 社区互动 (R46)
- 个人渊源故事 + 粉丝福利 + 呼唤社区

### 写作方法论 (R45)
- 可用 0x 小标题；学术/实践引用；付费隐藏段

### 随笔 (R33-R38)
- **禁用 0x 小标题**
- 白描 + 内省 + 单隐喻 + 开放结尾；情绪克制

## 发布前质检闸门
写完跑 `python3 review_before_publish.py <草稿>`：
- 情感弧线(R11) / 句子节奏(R12) / 情绪词密度(R13)
- 据 ⚠ 项微调后重跑，至节奏/情感达标。清单型"免费"主题词致密度偏高属正常。
