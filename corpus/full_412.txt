这篇文章介绍了一款名为 WUB（Windows Update Blocker）的免费小工具，旨在彻底解决 Windows 10 和 Windows 11 系统频繁自动更新的困扰。作者认为常规的修改注册表等方法既麻烦又不稳定，而此软件仅 939KB，无需安装，可以一键禁用或恢复系统更新。
文章提供了详细的使用步骤，只需以管理员权限运行程序，点击“Disable Updates”并应用即可永久停止更新；如需恢复，同样可一键启用。此外，软件还提供了查看受影响服务列表等额外设置选项。
恼人的更新
自从 Windows 10 出来之后，直到现在的 Windows 11，Windows 一直会时不时地给你推荐并自动安装系统更新。这不仅在关机的时候要等待更新完毕，有时还会影响到电脑的正常使用。
非常的烦人。
但是，如果你在网上搜索如何关掉 Windows 自动更新的教程，它会给你推荐更改注册表、下载各种各样软件、修改设置等等。但是，这不仅设置起来非常麻烦，并且效果也不稳定。
有没有一种一键可以关闭 Windows 自动更新的软件呢？稳定好用？
有的兄弟，今天就给你推荐一下。它不仅可以一键自动关掉 Windows 自动更新，永远不会再弹出提醒，并且软件只有 939K，不需要安装，使用完之后删除都可以。非常的简洁方便，符合我的好软件的价值观。

关闭更新
在下载之后，直接在你的电脑上面双击exe文件运行程序（一定要以管理员权限运行）。会弹出下面的一个小的窗口。
点击
Disable Updates
，然后选择
apply now
，像我图中这样设置就完成了。
好了，软件的使用教程就介绍完毕了。一句话就可以说完，是不是非常的简单？
这时如果你进入设置，点击 Windows 更新，甚至手动刷新更新，都不会进行 Windows 的自动更新，甚至会报错。
恢复更新
如果你后悔了想要恢复更新，或者在使用一段时间之后想要获得 Windows 的最新版本，无论如何，你这个时候需要恢复 Windows 的自动更新了。那么怎么办呢？
也不用怕，直接再次打开这个软件，选择
enable updates
，重新点击
apply now
，就可以恢复 Windows 的自动更新了。
